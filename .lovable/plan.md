# Brand Story 첫 화면 구성

## 작업 내용
- 첨부 이미지에서 창업 당시 사진, 1·2·3대 인물 사진, 제품 사진을 분리해 사용합니다.
- 중국어 문구는 노출하지 않고 한국어 중심에 짧은 영어 표기를 더합니다.
- 1930년 상하이에서 시작된 역사, 3대 계승, 장인정신과 원료 철학을 한 페이지 흐름으로 구성합니다.
- 현재 사이트의 헤더·푸터·색상·글꼴은 유지하며 PC와 모바일에서 자연스럽게 재배치합니다.

## 화면 구성
1. `EIICHI ISHINO`와 3대 계승 메시지
2. 1930년 창업 역사와 옛 상점 사진
3. 1대·2대·3대 계승 이야기
4. 장인 제작·세대 계승·원료 탐구의 브랜드 가치

## 참고
- 첨부 이미지의 중국어는 번역용 참고만 하고 페이지에는 한국어와 영어만 사용합니다.
- 이번에는 이 한 장에 담긴 내용만 구현하고 이후 상세 내용이 들어갈 자리를 자연스럽게 열어 둡니다.
