# 네이버 검색 색인 기본 최적화

## 적용 내용
- 홈페이지 제목을 `수제비누, 일본 명품 수제비누, Ei 비누, 준코클래식, 일본 미용비누`로 변경합니다.
- 홈페이지 설명과 공유용 제목·설명을 요청한 문구로 통일합니다.
- 홈페이지에 `https://eisoap.com/` 자기참조 canonical과 `og:url`을 추가합니다.
- 공개 페이지와 제품 상세 페이지를 포함한 `/sitemap.xml`을 만들고 `robots.txt`에서 안내합니다.
- 로그인·장바구니·결제·마이페이지·관리자 등 검색 결과에 노출되면 안 되는 페이지는 사이트맵에서 제외합니다.
- 적용 후 사이트맵 응답, 페이지 메타 정보, 빌드 상태를 확인합니다.

## 기술 세부사항
- TanStack Router의 페이지별 검색 설정과 공개 경로 목록을 기준으로 사이트맵을 자동 생성합니다.
- 사이트맵 주소는 공식 도메인 `https://eisoap.com`을 사용하며 임의의 수정일은 넣지 않습니다.
- 기존 네이버 소유 확인 태그와 검색엔진 크롤링 허용 설정은 유지합니다.
