# 스크롤 텍스트 하이라이트 적용

## 적용 범위
- 브랜드 스토리의 핵심 소개 문구를 스크롤 위치에 맞춰 한 줄씩 밝게 전환합니다.
- 홈의 제품 소개 문구에도 같은 계열의 잔잔한 하이라이트를 적용해 전체 경험을 통일합니다.
- 브랜드 스토리의 철학 영역은 화면에 머무는 고정 구간으로 구성하고, 스크롤 진행에 따라 문장이 순차적으로 강조되게 합니다.

## 움직임
- 초기 글자는 낮은 불투명도로 보이고, 활성화될 때 선명해지며 약간 위로 이동합니다.
- 빠른 튐 없이 긴 완화 곡선을 사용하고, 스크롤을 위로 올리면 자연스럽게 되돌아갑니다.
- 모바일에서는 고정 구간을 짧게 하거나 일반 흐름으로 완화해 답답함과 화면 겹침을 방지합니다.
- 사용자가 ‘동작 줄이기’를 설정한 경우 효과 없이 모든 글자를 선명하게 표시합니다.

## 기술 세부사항
- 재사용 가능한 스크롤 진행 감지 훅과 문장 단위 텍스트 컴포넌트를 추가합니다.
- 브라우저 스크롤 위치를 requestAnimationFrame으로 계산해 부드럽게 갱신합니다.
- 기존 색상, 글꼴, 문구, 이미지, 페이지 구조는 유지하고 움직임만 추가합니다.
- 데스크톱과 모바일에서 글자 겹침, 고정 구간 높이, 전환 순서를 실제 화면으로 확인합니다.
