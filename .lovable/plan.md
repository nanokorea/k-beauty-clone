# 회원가입·회원 기능·문의·인증 메일 개선

## 구현 내용
- 회원가입 아이디 입력 옆에 `중복 확인`을 추가하고, 확인 전에는 가입할 수 없게 합니다.
- 비밀번호와 비밀번호 확인란에 실시간 사용 가능 여부 및 일치 상태를 표시합니다.
- 가입 인증 안내 화면에 가입한 아이디와 이메일을 함께 표시합니다.
- 마이페이지에 현재 비밀번호, 새 비밀번호, 새 비밀번호 확인을 받는 비밀번호 변경 영역을 추가합니다.
- 기존 문의 화면을 `1:1 문의하기`로 명확히 바꾸고 상단·하단 고객센터 및 마이페이지에서 바로 이동할 수 있게 합니다.
- 회원가입 인증 메일에 제공된 비누 사진을 옅은 배경 이미지로 적용하고, 전화번호 옆에 `www.Eisoap.com` 링크를 표시합니다.

## 확인
- 회원가입 확인 상태와 비밀번호 변경 입력 검증을 확인합니다.
- 1:1 문의 화면 진입과 문의 저장 흐름을 확인합니다.
- 데스크톱·모바일 화면 및 인증 메일 미리보기, 전체 빌드 상태를 확인합니다.

## 기술 세부사항
- 비밀번호 변경은 로그인한 회원에게 현재 비밀번호를 다시 확인한 뒤 처리합니다.
- 아이디 중복 확인 결과는 아이디가 수정되면 즉시 초기화합니다.
- 메일 배경은 이메일 앱 호환성을 위해 외부 이미지 URL과 반투명한 밝은 본문 영역을 함께 사용합니다.
